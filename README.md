# ASA STUDIO — HIPHOP / GLITCH EDITION

GitHub Pages에 바로 업로드 가능한 완성본입니다.

- `index.html`
- `ASA_BGM.mp3`
- `.nojekyll`

## 주요 연출
- ASA 부팅/글리치 인트로
- CLICK / ENTER 입장
- 입장과 동시에 BGM 시작
- 커스텀 BGM HUD (재생/정지/볼륨/탐색)
- 스트리트 에디토리얼 + 글리치 스타일
- 파티클, 스캔라인, 마우스 라이트, 스크롤 애니메이션
- 실제 포트폴리오 5종 + 카카오 상담
- ASA 키보드 이스터에그

브라우저 정책상 소리는 첫 클릭/Enter 입력 이후 재생됩니다.
