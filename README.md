# ASA STUDIO — PORTFOLIO / GLITCH EDITION

GitHub Pages에 바로 업로드 가능한 완성본입니다.

## 포함 파일
- `index.html`
- `ASA_BGM.mp3`
- `.nojekyll`

## 포트폴리오
총 11개 길드 페이지가 등록되어 있습니다.
- 료칸 / 은오 / NOXX / 별관 / GRIM
- 도시 / 호천 / Playlist / 보글 / 둥근달 / 도쿄

## 주요 연출
- ASA 부팅/글리치 인트로
- CLICK / ENTER 입장
- 사용자 입력 후 BGM 시작
- 커스텀 BGM HUD (재생/정지/볼륨/탐색)
- 스트리트 에디토리얼 + 글리치 스타일
- 11개 포트폴리오 반응형 카드 그리드
- 프로젝트별 고유 컬러/분위기
- 파티클, 스캔라인, 마우스 라이트, 스크롤 애니메이션
- 카카오 상담 CTA
- ASA 키보드 이스터에그
- `prefers-reduced-motion` 접근성 대응

브라우저 자동재생 정책상 소리는 첫 클릭/Enter 입력 이후 재생됩니다.
