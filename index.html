03 · PROCESS

자료만 보내주세요.

길드 분위기와 필요한 내용을 전달받아 하나의 완성된 페이지로 구성합니다.

01 / CONTACT

상담

원하는 분위기, 길드 정보, 참고 페이지와 필요한 기능을 이야기합니다.

02 / CONTENT

자료 전달

길드명, 소개, 규칙, 일정, 링크, 이미지, 사용할 음악 등의 자료를 전달합니다.

03 / BUILD

디자인 · 제작

길드만의 컬러와 컨셉을 잡고 PC·모바일 화면과 인터랙션을 제작합니다.

04 / DELIVERY

완성

최종 확인 후 GitHub Pages에 사용할 수 있는 페이지 파일을 전달합니다.

04 · FAQ

자주 묻는 내용.

어떤 자료를 준비하면 되나요?

길드명, 길드 소개, 규칙/가입 조건/일정 같은 게시할 내용과 원하는 분위기를 알려주세요. 로고·스크린샷·BGM이 있다면 함께 전달하면 더 개성 있게 구성할 수 있습니다.

휴대폰에서도 볼 수 있나요?

네. 기본적으로 데스크톱과 모바일 화면을 함께 고려한 반응형 페이지로 제작합니다.

음악이나 시작 화면도 넣을 수 있나요?

가능합니다. 실제 포트폴리오처럼 입장 화면, BGM 재생/정지, 음량 조절 등의 연출을 페이지 컨셉에 맞춰 구성할 수 있습니다.

예시와 완전히 다른 분위기도 가능한가요?

가능합니다. 기존 작업물을 그대로 복사하는 방식보다 길드의 이름, 성격, 원하는 색과 분위기에 맞춰 새로운 방향을 잡는 것을 기본으로 합니다.

가격과 제작 기간은 어떻게 되나요?

페이지 분량과 기능에 따라 달라질 수 있어 오픈카카오 상담에서 필요한 내용을 확인한 뒤 안내합니다.
