# ASA STUDIO — Guild Page Portfolio

길드 홍보/안내 페이지 제작 포트폴리오 랜딩 페이지입니다.

## GitHub Pages 배포
1. 이 ZIP의 압축을 풉니다.
2. `index.html`을 저장소 루트에 업로드합니다.
3. GitHub 저장소 → Settings → Pages에서 배포 브랜치를 설정합니다.
4. 별도 빌드가 필요하지 않습니다.

## 포함 기능
- 반응형 PC/모바일 디자인
- 파티클 스타 배경
- 마우스 추적 라이트/커스텀 커서
- 스크롤 reveal 애니메이션
- 5개 실제 포트폴리오 링크
- 기능/제작과정/FAQ/상담 CTA
- Open Kakao 상담 연결
- `ASA` 키보드 이스터에그
- OG/SEO 기본 메타 태그

## 수정
`index.html` 하나에서 문구, 링크, 색상 등을 수정할 수 있습니다.
